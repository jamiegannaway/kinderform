# Policy topics (draft)

Every row in `policies.csv` gets one topic code from this list. A state can have several rows for one topic, for example one for fostering and one for adoption, or one per rule.

The register records what a rule says. It does not judge the rule, and it does not assess anyone against it.

This list is a draft. Add a code when a rule fits none of these, and say why in the pull request.

## Who can apply

| Code | Covers |
|---|---|
| `min_age` | Minimum age to foster or adopt |
| `max_age` | Any upper age limit, or a rule on the age gap between carer and child |
| `relationship_status` | Rules on single applicants, married or unmarried couples, and how long a couple must have been together |
| `nondiscrimination` | Stated rules on sexual orientation, gender identity, religion, race or disability of applicants |
| `residency` | Living in the state, or citizenship or immigration status |
| `language` | Language requirements |
| `education` | Literacy or education requirements |
| `income` | Income or financial stability requirements |
| `employment` | Rules on working applicants, or a carer staying at home |
| `health` | Health requirements and the medical statement |

## The home

| Code | Covers |
|---|---|
| `housing_tenure` | Whether renting is allowed, and any landlord consent |
| `bedroom_space` | Bedroom sharing, square footage, beds and space |
| `home_safety` | Home inspection, fire, water, medication storage and first aid rules |
| `firearms` | Storage and disclosure of firearms |
| `smoking` | Smoking and vaping rules |
| `pets` | Animals in the home, including vaccinations |
| `transport` | Driving licence, vehicle insurance and car seat rules |
| `capacity` | The most children allowed in a home, including the carer's own |

## Checks and assessment

| Code | Covers |
|---|---|
| `background_checks` | Criminal record checks, fingerprinting and who in the household is checked |
| `child_abuse_registry` | Checks against child abuse and neglect registries, including other states' |
| `references` | How many references, and from whom |
| `home_study` | The home study or family assessment, and the model used |
| `training_preservice` | Training before licensing or approval, in hours, and the curriculum |
| `training_ongoing` | Training each year after licensing |

## Licence and timing

| Code | Covers |
|---|---|
| `licence_type` | The types of licence or approval (for example foster only, foster-adopt, kinship, therapeutic) |
| `licence_term` | How long a licence lasts |
| `renewal` | What renewal involves |
| `timeline` | A stated time from application to licence or approval, in statute, regulation or on the agency's pages |
| `kinship` | Rules or waivers that apply only to relatives or close family friends |
| `waivers` | General rules on waiving or varying a requirement |

## Support and money

| Code | Covers |
|---|---|
| `board_rate` | Monthly foster care maintenance payments |
| `adoption_assistance` | Adoption subsidy, Medicaid and one-off cost reimbursement |
| `fees` | Any fees charged to applicants by public agencies |
| `other` | Anything else; describe it in `rule_summary` |
